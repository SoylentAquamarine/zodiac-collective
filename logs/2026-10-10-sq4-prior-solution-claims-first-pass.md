# SQ-4 — first pass: cataloguing publicly claimed Z13 solutions (cipher-only half)

**Trigger:** actively searching for an unclaimed thread this cycle. ChatGPT's own last steering call
("stop extending the same null methodology... candidate discovery remains the real, unchanged blocker")
names exactly what SQ-4 exists to supply, and `config/sidequests.md` itself says SQ-4 "can begin
immediately and run in parallel with everything else" — yet it had no Status entry at all and no
`data/` deliverable, unlike every other sidequest in this project.

## What's already known / not done yet

Already known: SQ-3's methodology (bigram-chain planted-recovery, repeat-structure awareness) is
thoroughly cross-checked and has nothing further to add without a real candidate to test. Not done: SQ-4's
actual deliverable, a sourced catalog of previously publicized claimed Z13 solutions, had never been
started.

## Design and why it's non-circular

Search for publicly documented Z13 solution claims (not from memory), catalog each with proposer, date,
claimed method, and documented critique/rejection status. Per the project's own standing ethical boundary
(`README.md`, `CONTRIBUTING.md`) plus the stricter standing project-level instruction that the
named-suspect-theories half of SQ-4 is deliberately left unstarted pending explicit user confirmation:
any claim whose proposed plaintext names or implies a real suspect is recorded only generically (existence,
proposer, date, critique), with the specific claimed name withheld this cycle.

## Honesty precommitment

Report every claim found exactly as sourced, including which ones are being deliberately left
under-recorded for the stated ethical/scope reason, rather than silently omitting them or quietly
including suspect content without flagging it.

## Result

Three claims catalogued in `data/sq4-prior-solution-claims-catalog.md`:

1. **Craig P. Bauer's "ALFRED E. NEUMAN"** — a named cryptographer/historian's proposal, structurally
   argued from Z13's first three symbols decoding to "AEN." Not a suspect claim (a fictional mascot). Not
   independently verified.
2. **A 2021 claim** (proposer publicly named in sourcing, but the claimed plaintext is reported to name a
   suspect) — recorded only generically per this cycle's scope decision, with named expert reactions on
   both sides of its cryptologic soundness.
3. **A structural falsification method in active use** — the same repeat-position equality constraints
   already on file as a directly-fetched-tier Confirmed Finding (positions 1=12, 3=11, 5=7=9, 8=13) are
   shown being actively applied by an outside critic to falsify a real 2025/2026 candidate claim. Not new
   structural knowledge for this project, but a concrete demonstration of the project's own planned
   flexibility-testing approach already happening in the wild.

All three are search-synthesis tier only this cycle — none directly fetched from a primary document.
Disclosed as a real limitation, not upgraded.

## Decision

This is SQ-4's real first substantive pass, not a completed catalog — more publicly claimed Z13 solutions
almost certainly exist beyond these three. The single most valuable concrete next step for SQ-3 specifically
is applying the project's own already-confirmed repeat-position rule (see Claim 3's cross-check) to Bauer's
"ALFRED E. NEUMAN" claim once SQ-1's canonical transcription exists, since that's a fully cipher-only check
with no suspect dimension at all. Candidate discovery (the actual named blocker per ChatGPT's own last
call) now has real, citable, cipher-only material on file for the first time.
