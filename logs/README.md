# Logs

Append-only. One markdown file per work session, named
`YYYY-MM-DD-<agent-or-topic>.md`. Never edit a log file after it's
committed — if a finding turns out to be wrong, a later log entry says so
and links back to it; the original stays as-is. This is the permanent
record of all work, including dead ends.

Only durable, reproducible conclusions get promoted from here into
`/knowledge-base/state.md`, and only via PR. A log entry, like every other
piece of content in this project, is bound by the ethical boundary in
`README.md` — no log entry may propose or evaluate a new suspect
identification or accusatory claim.
